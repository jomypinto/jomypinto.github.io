Módulo 01

Fundamentos de LLMs e Transformers

Aprenda a arquitetura dos modelos base baseados em Transformers (Self-Attention, Positional Encoding), tokenização avançada e como utilizar bibliotecas standard para carregar e inferir modelos de linguagem.

Instalação do Ambiente 

pip install torch transformers tokenizers datasets

Ferramentas e Requisitos

  • Python 3.10+ com suporte CUDA
  • Hugging Face `transformers` v4.38+
  • GPU com mínimo de 8GB VRAM (para modelos 7B quantizados)

Exemplo Prático: Carregamento e Inferência Local 

from transformers import AutoModelForCausalLM, AutoTokenizer
import torch

model_id = "meta-llama/Llama-3.2-1B-Instruct"

tokenizer = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(
    model_id, 
    torch_dtype=torch.bfloat16, 
    device_map="auto"
)

messages = [{"role": "user", "content": "Explica o mecanismo de Self-Attention em 2 frases."}]
inputs = tokenizer.apply_chat_template(messages, return_tensors="pt").to("cuda")

outputs = model.generate(inputs, max_new_tokens=100)
print(tokenizer.decode(outputs[0], skip_special_tokens=True))
Módulo 02

Engenharia de Prompt Avançada

Técnicas estruturadas para maximizar a precisão das respostas: Chain-of-Thought (CoT), Few-Shot Prompting, Tree of Thoughts (ToT), e estruturação de dados através de formatos como JSON e Pydantic.

Dependências Recomendadas 

pip install langchain langchain-openai pydantic instructor

Parâmetros Críticos

  • Temperature: 0.0 (deterministico) a 0.7 (criativo)
  • Top-P (Nucleus Sampling): 0.9 para variabilidade controlada
  • System Prompt: Define o papel, restrições e formato

Exemplo Prático: Extração de Dados Estruturados com Pydantic 

from pydantic import BaseModel, Field
import instructor
from openai import OpenAI

class ExtrairEntidades(BaseModel):
    empresa: str = Field(description="Nome da empresa mencionada")
    tecnologia: str = Field(description="Tecnologia ou produto principal")
    sentimento: str = Field(description="Sentimento geral: Positivo, Neutro, Negativo")

client = instructor.patch(OpenAI(api_key="SUA_API_KEY"))

resposta = client.chat.completions.create(
    model="gpt-4o-mini",
    response_model=ExtrairEntidades,
    messages=[{"role": "user", "content": "A OpenAI lançou o modelo GPT-4o e foi recebido com grande entusiasmo pela comunidade."}]
)

print(resposta.model_dump_json(indent=2))
Módulo 03

Sistemas RAG (Retrieval-Augmented Generation)

Construção de pipelines de RAG completos para conectar LLMs a bases de dados privadas. Envolve fragmentação de documentos (chunking), vetorização e re-ranking de respostas.

Instalação do RAG Stack 

pip install llama-index chromadb sentence-transformers pypdf

Arquitetura RAG

  1. Parseamento e Chunking de ficheiros PDF/Texto
  2. Geração de Embeddings (ex: `bge-small-en-v1.5`)
  3. Armazenamento e busca por Similaridade de Cosseno

Exemplo Prático: RAG com LlamaIndex 

from llama_index.core import VectorStoreIndex, SimpleDirectoryReader
import os

# Carregar documentos da pasta local ./documentos
documents = SimpleDirectoryReader("./documentos").load_data()

# Criar índice vetorial
index = VectorStoreIndex.from_documents(documents)

# Criar motor de consulta
query_engine = index.as_query_engine()
resposta = query_engine.query("Qual é o procedimento de segurança descrito nos manuais?")

print(resposta)
Módulo 04

Bases de Dados Vetoriais (Vector Databases)

Gestão e indexação de grande volume de embeddings com tecnologias como Qdrant, ChromaDB, Pinecone e a extensão `pgvector` para PostgreSQL.

Instalação Qdrant & Docker 

# Arrancar Qdrant via Docker
docker run -p 6333:6333 qdrant/qdrant

# Instalar cliente Python
pip install qdrant-client

Algoritmos de Indexação

  • HNSW: Hierarchical Navigable Small World (alta performance)
  • Métricas: Cosine, Euclidean, Dot Product
  • Payload Filtering: Filtro de metadados antes/durante a busca

Exemplo Prático: Inserção e Pesquisa no Qdrant 

from qdrant_client import QdrantClient
from qdrant_client.models import Distance, VectorParams, PointStruct

client = QdrantClient("http://localhost:6333")

# Criar Coleção
client.recreate_collection(
    collection_name="manuals",
    vectors_config=VectorParams(size=4, distance=Distance.COSINE),
)

# Inserir vetores com metadados
client.upsert(
    collection_name="manuals",
    points=[
        PointStruct(id=1, vector=[0.05, 0.61, 0.76, 0.17], payload={"categoria": "infraestrutura"}),
        PointStruct(id=2, vector=[0.19, 0.81, 0.75, 0.11], payload={"categoria": "segurança"})
    ]
)

# Consulta por similaridade
search_result = client.search(
    collection_name="manuals",
    query_vector=[0.2, 0.8, 0.7, 0.1],
    limit=1
)
print(search_result)
Módulo 05

Agentes Autónomos e Multi-Agent Systems

Sistemas autónomos baseados na arquitetura ReAct (Reason + Act), com capacidade para execução de ferramentas externas, reflexão e colaboração entre múltiplos agentes através de CrewAI ou LangGraph.

Instalação CrewAI 

pip install crewai crewai-tools

Conceitos Chave

  • Role & Goal: Definição precisa das atribuições do agente
  • Tools: Permissão para ler APIs, executar Python ou ler ficheiros
  • Process: Sequencial ou Hierárquico

Exemplo Prático: Agente Investigador com CrewAI 

from crewai import Agent, Task, Crew, Process

investigador = Agent(
    role='Investigador Tecnológico',
    goal='Analisar as novidades do Llama-3',
    backstory='És um analista sénior especialista em arquitetura de LLMs.',
    verbose=True
)

tarefa = Task(
    description='Compila os 3 principais avanços do Llama-3 num resumo executivo.',
    expected_output='Um relatório em Markdown com 3 tópicos.',
    agent=investigador
)

crew = Crew(agents=[investigador], tasks=[tarefa], process=Process.sequential)
resultado = crew.kickoff()
print(resultado)
Módulo 06

Fine-Tuning e Adaptação Eficiente (PEFT/LoRA)

Ajuste fino de modelos de linguagem de código aberto utilizando técnicas com baixo consumo de recursos de GPU (QLoRA, PEFT, Unsloth) e alinhamento por preferências com DPO/RLHF.

Dependências de Fine-Tuning 

pip install trl peft bitsandbytes accelerate datasets

Configuração LoRA

  • r (Rank): 8 ou 16 (dimensão das matrizes adaptativas)
  • lora_alpha: Geralmente 16 ou 32
  • target_modules: `q_proj`, `v_proj`, `k_proj`, `o_proj`

Exemplo Prático: Treino com SFTTrainer (TRL) 

from trl import SFTTrainer
from peft import LoraConfig
from transformers import TrainingArguments

peft_config = LoraConfig(
    r=16,
    lora_alpha=32,
    lora_dropout=0.05,
    target_modules=["q_proj", "v_proj"],
    task_type="CAUSAL_LM"
)

training_args = TrainingArguments(
    output_dir="./resultados_lora",
    per_device_train_batch_size=2,
    gradient_accumulation_steps=4,
    learning_rate=2e-4,
    logging_steps=10,
    max_steps=100
)

# SFTTrainer recebe o modelo, dataset e a peft_config para treino rápido

Módulo 08

Avaliação e Benchmarking de Modelos (LLM Evaluation)

Metodologias rigorosas para testar alucinações, assertividade e qualidade das respostas usando frameworks como Ragas, TruLens e avaliação assistida por LLM (LLM-as-a-Judge).

Instalação Framework RAGAS 

pip install ragas datasets

Métricas Principais

  • Faithfulness: A resposta baseia-se unicamente no contexto?
  • Answer Relevance: A resposta responde à pergunta colocada?
  • Context Precision: Qualidade do ranking de documentos recuperados

Exemplo Prático: Avaliação RAGAS 

from ragas import evaluate
from ragas.metrics import faithfulness, answer_relevancy
from datasets import Dataset

data_samples = {
    'question': ['Onde fica a sede da empresa?'],
    'answer': ['A sede fica em Lisboa, Portugal.'],
    'contexts': [['A nossa empresa tem a sua sede central localizada no centro de Lisboa.']],
    'ground_truth': ['Lisboa, Portugal']
}

dataset = Dataset.from_dict(data_samples)
score = evaluate(dataset, metrics=[faithfulness, answer_relevancy])
print(score.to_pandas())
Módulo 09

Segurança, AI Safety e Guardrails

Proteção contra ataques de Prompt Injection, fugas de dados (PII Leakage) e aplicação de políticas de moderação com NeMo Guardrails, Llama Guard e Guardrails AI.

Instalação Guardrails 

pip install guardrails-ai Presidio-analyzer Presidio-anonymizer

Vetores de Ameaça

  • Direct Prompt Injection: Suplantar regras do sistema
  • Indirect Prompt Injection: Injeção através de sites/PDFs lidos
  • Data Exfiltration: Obtenção indevida de dados pessoais

Exemplo Prático: Anonimização de PII com Microsoft Presidio 

from presidio_analyzer import AnalyzerEngine
from presidio_anonymizer import AnonymizerEngine

texto = "O contacto do cliente João Silva é joao.silva@email.com e o telefone é 912345678."

analyzer = AnalyzerEngine()
anonymizer = AnonymizerEngine()

resultados = analyzer.analyze(text=texto, entities=["PERSON", "EMAIL_ADDRESS", "PHONE_NUMBER"], language="en")
texto_protegido = anonymizer.anonymize(text=texto, analyzer_results=resultados)

print(texto_protegido.text)
# Saída: O contacto do cliente  é  e o telefone é .

Módulo 11

IA Multimodal (Visão, Áudio e Vídeo)

Construção de aplicações capazes de interpretar e gerar múltiplos tipos de dados: processamento de imagem com Vision LLMs (GPT-4o, Llama-Vision), síntese/transcrição de áudio com Whisper e processamento documental avançado.

Instalação Whisper & Pillow 

pip install openai-whisper pillow openai

Casos de Uso Multimodais

  • OCR e extração de tabelas de faturas e recibos
  • Transcrição e sumarização automática de reuniões
  • Inspeção visual automatizada de qualidade

Exemplo Prático: Análise de Imagem com Vision API 

from openai import OpenAI
import base64

client = OpenAI()

def encode_image(image_path):
    with open(image_path, "rb") as image_file:
        return base64.b64encode(image_file.read()).decode('utf-8')

base64_image = encode_image("diagrama.png")

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "Descreve este diagrama de arquitetura de rede:"},
                {"type": "image_url", "image_url": {"url": f"data:image/png;base64,{base64_image}"}}
            ],
        }
    ]
)

print(response.choices[0].message.content)
Módulo 12

Edge AI e Execução Local / On-Device

Otimização e execução de LLMs diretamente em dispositivos do utilizador ou servidores locais com restrições de privacidade e ausência de ligação à internet, recorrendo a Llama.cpp, MLX (Apple Silicon) e ONNX Runtime.

Llama-cpp-python Setup 

# Instalação com suporte para aceleração Metal/CUDA
CMAKE_ARGS="-DLLAMA_CUDA=on" pip install llama-cpp-python

Formato GGUF e Níveis

  • Q4_K_M: Excelente equilíbrio entre performance e memória
  • Q8_0: Praticamente sem perda de precisão relativamente ao FP16
  • Offloading: Transferência parcial de camadas para GPU/VRAM

Exemplo Prático: Inferência Local com llama-cpp-python 

from llama_cpp import Llama

# Carregar modelo quantizado localmente
llm = Llama(
    model_path="./models/llama-3-8b-instruct.Q4_K_M.gguf",
    n_gpu_layers=-1, # Carregar todas as camadas para GPU
    n_ctx=2048
)

output = llm(
    "Q: Quais são as vantagens de executar modelos On-Device?\nA:",
    max_tokens=150,
    stop=["Q:", "\n"]
)

print(output["choices"][0]["text"])
Módulo 13

Governação, Regulamentação (EU AI Act) e Ética em IA

Enquadramento legal e boas práticas de conformidade com o Regulamento Europeu de Inteligência Artificial (EU AI Act), avaliação de impacto em direitos fundamentais, explicabilidade e transparência.

Categorias de Risco (EU AI Act)

  • Inaceitável: Social scoring, manipulação comportamental
  • Alto Risco: Recrutamento, saúde, infraestruturas críticas
  • Risco Limitado/Mínimo: Chatbots, geradores de conteúdo (exigem transparência)

Checklist de Conformidade

  • Registo de Logs de Auditoria e Traçabilidade
  • Supervisão Humana (Human-in-the-loop)
  • Notificação clara ao utilizador final sobre interação com IA

Exemplo Prático: Padrão de Resposta com Marcação de Transparência 

def gerar_resposta_com_transparencia(prompt_utilizador):
    # Regra de Conformidade Artigo 50º EU AI Act (Notificação de Transparência)
    disclaimer = "[Aviso: Esta resposta foi gerada por um sistema automatizado de IA (Modelo LLM).]\n\n"
    
    # Processar com o modelo...
    resposta_ia = "O procedimento para atualização do sistema envolve 3 passos..."
    
    return disclaimer + resposta_ia

print(gerar_resposta_com_transparencia("Como atualizo o sistema?"))
