Experiência Prática com LLMs de Última Geração

GPT, Gemini, Claude, Llama, Mistral e SLMs em produção

Prerequisito: Python (Básico)

Ambiente e Dependências Necessárias

Para executar modelos locais com aceleração de GPU e integrar APIs proprietárias, configure o seguinte ecossistema:

# 1. Instalar Ollama no Linux/WSL2 para gestão de open-weights

curl -fsSL https://ollama.com/install.sh | sh


# 2. Criar ambiente virtual e instalar SDKs de inferência e vLLM

python3 -m venv .venv && source .venv/bin/activate

pip install openai anthropic google-genai vllm llama-cpp-python unsloth

Configuração de Parâmetros de Inferência e vLLM

Exemplo de ficheiro de configuração YAML para serving com vLLM e parâmetros de temperatura/top_p:

# config_vllm.yaml
model: "meta-llama/Llama-3.1-8B-Instruct"
tensor_parallel_size: 1
gpu_memory_utilization: 0.85
max_model_len: 8192
quantization: "awq" # Reduz consumo de VRAM
dtype: "auto"
port: 8000

Código Hands-on: Benchmarking e Cálculo de TTFT

Script Python para medir o Time-To-First-Token (TTFT) entre o Llama local e a API da OpenAI:

import time
from openai import OpenAI

client = OpenAI(base_url="http://localhost:11434/v1", api_key="ollama")

start_time = time.time()
response = client.chat.completions.create(
    model="llama3.1",
    messages=[{"role": "user", "content": "Gera um script Bash de hardening de SSH."}],
    stream=True
)

first_token = True
for chunk in response:
    if first_token and chunk.choices[0].delta.content:
        ttft = time.time() - start_time
        print(f"TTFT (Time to First Token): {ttft:.4f}s")
        first_token = False
    print(chunk.choices[0].delta.content or "", end="")

Melhores Práticas & Desempenho em Produção

  • Escolha da Quantização: Utilize quantização Q4_K_M em ambientes com restrição de VRAM sem perda percetível de capacidade de raciocínio.
  • Uso de SLMs (Small Language Models): Para tarefas de classificação de logs ou parsing de PII, prefira modelos menores (ex.: Phi-4 ou Qwen-2.5 3B) para otimizar custos e reduzir a latência.
  • Fallback Strategy: Configure um gateway com fallback automático (ex.: LiteLLM Proxy) para redirecionar pedidos caso a API principal devolva erro 429 ou 5xx.
