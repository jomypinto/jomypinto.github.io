1. Engenharia e Inversão de Código

Análise estática e dinâmica de binários executáveis, ficheiros APK e IPA para identificação de vulnerabilidades e engenharia reversa.

Aplicações Recomendadas: Ghidra, Frida, Apktool, Cutter.

  1. Instalação do Ghidra (Requer Java 17+): 
    sudo apt update && sudo apt install openjdk-17-jdk -y
wget https://github.com/NationalSecurityAgency/ghidra/releases/download/Ghidra_11.0_build/ghidra_11.0_PUBLIC_20231222.zip
unzip ghidra_11.0_PUBLIC_20231222.zip && cd ghidra_11.0_PUBLIC && ./ghidraRun
  2. Instalação da CLI da Frida via Python: 
    pip install frida-tools frida

2. Segurança Ofensiva e Red Teaming

Simulação de ataques adversariais, testes de intrusão e avaliação de posturas de segurança em redes de suporte empresarial.

Aplicações Recomendadas: Metasploit Framework, Nmap, Burp Suite.

  1. Instalação do Nmap e Metasploit Framework: 
    sudo apt update && sudo apt install nmap -y
curl https://raw.githubusercontent.com/rapid7/metasploit-omnibus/master/config/templates/metasploit-framework-wrappers/msfupdate.erb > msfinstall
chmod 755 msfinstall && ./msfinstall

3. Operações de Segurança e SIEM

Centralização, agregação e correlação de eventos de segurança em tempo real para deteção de ameaças e resposta a incidentes (SOC).

Aplicações Recomendadas: Wazuh SIEM/XDR, Elastic Stack (ELK).

  1. Implantação Rápida do Wazuh SIEM via Docker: 
    git clone https://github.com/wazuh/wazuh-docker.git -b v4.7.2
cd wazuh-docker/single-node
docker compose up -d

4. Gestão de Identidades e Acesso (IAM)

Federação de identidades, Single Sign-On (SSO) e controlo de acessos por função (RBAC) com protocolos OAuth2, OpenID Connect e SAML 2.0.

Aplicações Recomendadas: Keycloak, FreeIPA.

  1. Instalação do Keycloak via Docker Container: 
    docker run -d --name keycloak -p 8080:8080 -e KEYCLOAK_ADMIN=admin -e KEYCLOAK_ADMIN_PASSWORD=admin quay.io/keycloak/keycloak:23.0.0 start-dev

5. Forense Digital e Investigação

Análise e preservação da cadeia de custódia de dados em artefatos de memória RAM, discos rígidos e capturas de rede após incidentes.

Aplicações Recomendadas: Autopsy, Volatility 3, Wireshark.

  1. Instalação do Volatility 3 (Forense de Memória RAM): 
    git clone https://github.com/volatilityfoundation/volatility3.git
cd volatility3
pip install -r requirements.txt
python3 vol.py -h

6. Auditoria e Segurança de IA

Análise de modelos de Machine Learning quanto a envenenamento de dados, injeção de *prompts* e conformidade ética e regulatória.

Aplicações Recomendadas: Giskard, Garak, Adversarial Robustness Toolbox (ART).

  1. Instalação da Framework Garak (LLM Vulnerability Scanner): 
    python3 -m pip install -U garak
garak --help

7. Infraestrutura e Active Directory

Implementação e gestão de controladores de domínio, políticas de grupo (GPO), serviços Kerberos e auditorias de relações de confiança.

Aplicações Recomendadas: Samba4 AD-DC, BloodHound, RSAT.

  1. Provisionamento do Samba como Active Directory Domain Controller (Debian/Ubuntu): 
    sudo apt update && sudo apt install samba krb5-user winbind libpam-winbind -y
sudo samba-tool domain provision --use-rfc2307 --interactive

8. Desenvolvimento Web e Mobile

Criação de aplicações web modernas, Progressivas (PWA) e mobile com foco em reatividade, otimização e integração com serviços Firebase.

Aplicações Recomendadas: Node.js, React, Vite, Firebase CLI, Tailwind CSS.

  1. Instalação do Node.js (LTS) e Firebase CLI: 
    curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
sudo npm install -g firebase-tools

9. Cloud e Engenharia DevOps

Automação de pipelines CI/CD, orquestração de contentores e infraestrutura como código (IaC) para ambientes escaláveis.

Aplicações Recomendadas: Docker, Kubernetes (k3s), Terraform, Ansible.

  1. Instalação do Docker Engine e Docker Compose: 
    curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker $USER

10. Legislação, Controlo de Assiduidade e Compliance

Sistemas para registo de assiduidade, tempos de trabalho e gestão de dispensas em conformidade com o Código do Trabalho e o RGPD.

Aplicações Recomendadas: OrangeHRM, Odoo HR, TimeTrex.

  1. Implantação do OrangeHRM via Docker: 
    docker run -d --name orangehrm -p 8088:80 bitnami/orangehrm:latest

11. Gestão de Cuidados e Saúde

Aplicações e plataformas de apoio a cuidadores informais e profissionais para controlo de rotinas, consultas e planos de medicação.

Aplicações Recomendadas: Rota do Cuidador (App PWA), OpenEMR.

  1. Lançar o OpenEMR (Prontuário e Gestão de Saúde) via Docker: 
    docker run -d --name openemr -p 8300:80 openemr/openemr:7.0.2

12. Arquitetura de Sistemas e Redes

Desenho de topologias, segmentação de redes (VLANs), encaminhamento dinâmico e gestão de firewalls perimetrais.

Aplicações Recomendadas: GNS3, Wireshark, OPNsense.

  1. Instalação da CLI e Interface do GNS3 (Simulação de Redes): 
    sudo add-apt-repository ppa:gns3/ppa
sudo apt update
sudo apt install gns3-gui gns3-server -y

13. Cibersegurança Geral e Consciencialização

Treino de sensibilização, boas práticas de higiene digital, gestão de palavras-passe e prevenção contra ataques de engenharia social e phishing.

Aplicações Recomendadas: GoPhish, Bitwarden / Vaultwarden.

  1. Instalação do Servidor de Phishing Educacional GoPhish: 
    wget https://github.com/gophish/gophish/releases/download/v0.12.1/gophish-v0.12.1-linux-64bit.zip
unzip gophish-v0.12.1-linux-64bit.zip
chmod +x gophish && ./gophish
