PROBLEMA

Porque este projeto existe

Muitos laboratórios isolam tecnologias. Isso dificulta perceber como identidade, aplicações, endpoints e SIEM se relacionam durante um incidente real.

ABORDAGEM

Como foi estruturado

A arquitetura aproxima o laboratório de uma empresa funcional, com domínio, IAM, serviços, utilizadores, logs e monitorização centralizada.

RESULTADOS

O que demonstra

Esta secção deve evoluir com métricas, evidências, logs, capturas e decisões técnicas sempre que existirem dados concretos.

  • Cenários de autenticação e controlo de acessos.
  • Testes de SSO, MFA e RBAC.
  • Correlação de falhas de autenticação no SIEM.
  • Base para exercícios de deteção e resposta.

PRÓXIMA EVOLUÇÃO

A próxima camada deve incluir diagramas profissionais, screenshots reais, exemplos de configuração, logs e resultados de testes. Isso aumenta muito mais o valor do projeto do que acrescentar texto genérico.
