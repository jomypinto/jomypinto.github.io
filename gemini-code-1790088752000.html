import time, openai
client = openai.OpenAI(base_url="http://localhost:11434/v1", api_key="ollama")
t0 = time.time()
res = client.chat.completions.create(model="llama3.1", messages=[{"role": "user", "content": "Olá!"}], stream=True)
for chunk in res:
    if chunk.choices[0].delta.content:
        print(f"TTFT: {time.time()-t0:.4f}s"); break

Output Estruturado com Pydantic e Instructor

import instructor, openai
from pydantic import BaseModel

class UserLog(BaseModel):
    user_id: int
    action: str
    is_suspicious: bool

client = instructor.from_openai(openai.OpenAI())
log = client.chat.completions.create(
    model="gpt-4o-mini",
    response_model=UserLog,
    messages=[{"role": "user", "content": "Root login via SSH no port 22 às 03:00"}]
)
print(log.is_suspicious)

Endpoint Assíncrono com Streaming SSE em FastAPI

from fastapi import FastAPI
from fastapi.responses import StreamingResponse
import asyncio

app = FastAPI()

async def generate_stream():
    for i in range(5):
        yield f"data: Token {i}\n\n"
        await asyncio.sleep(0.2)

@app.get("/stream")
async def stream():
    return StreamingResponse(generate_stream(), media_type="text/event-stream")

Melhores Práticas

  • Utilizar chamadas I/O não-bloqueantes (async/await) em todas as invocações de APIs externas.

Re-ranking de Resultados com FlashRank

from flashrank import Ranker, RerankRequest

ranker = Ranker(model_name="ms-marco-MiniLM-L-12-v2")
query = "Qual a política de backups?"
passages = [
    {"id": 1, "text": "Os backups ocorrem diariamente às 02:00."},
    {"id": 2, "text": "A cantina serve refeições às 12:00."}
]
rerank_req = RerankRequest(query=query, passages=passages)
results = ranker.rerank(rerank_req)
print(results[0])

Melhores Práticas

  • Utilizar Chunking Semântico baseado em estruturas de documentos (títulos/parágrafos) em vez de divisão por tamanho fixo.
  • Usar Hybrid Search combinando busca vetorial densa com BM25 esparso para maximizar Recall.

Validação de Sanitização de Input em Python

import re

def sanitize_user_input(text: str) -> str:
    # Eliminar tentativas conhecidas de jailbreak
    forbidden_terms = ["ignore all previous instructions", "system prompt", "DAN mode"]
    cleaned = text
    for term in forbidden_terms:
        cleaned = re.sub(re.escape(term), "[REDACTED]", cleaned, flags=re.IGNORECASE)
    return cleaned

Orquestração de Equipa de Agentes com CrewAI

from crewai import Agent, Task, Crew

researcher = Agent(role="Investigador", goal="Analisar logs", backstory="Perito em forense")
writer = Agent(role="Redator", goal="Escrever relatório", backstory="Técnico de documentação")

task1 = Task(description="Procurar anomalias nos logs de rede", agent=researcher)
task2 = Task(description="Sintetizar achados num PDF", agent=writer)

crew = Crew(agents=[researcher, writer], tasks=[task1, task2])
# crew.kickoff()

Melhores Práticas

  • Limitar estritamente o número máximo de iterações do ciclo ReAct para evitar consumos excessivos de API.
  • Atribuir papéis (roles) e regras de atuação muito concisas a cada agente para prevenir conflitos de responsabilidade.

Pipeline GitHub Actions (CI/CD) com Testes Automáticos

name: AI App CI
on: [push]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Run Pytest & Promptfoo
        run: |
          pip install pytest promptfoo
          pytest tests/
          npx promptfoo eval

Melhores Práticas

  • Separar o serviço de inferência/orquestração da aplicação principal para garantir escalabilidade independente.
  • Armazenar chaves de API e credenciais em cofres de segredos (ex.: HashiCorp Vault, Azure Key Vault).
