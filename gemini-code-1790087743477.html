Script de Medição de TTFT (Time-To-First-Token)

import time, openai
client = openai.OpenAI(base_url="http://localhost:11434/v1", api_key="ollama")
t0 = time.time()
res = client.chat.completions.create(model="llama3.1", messages=[{"role": "user", "content": "Olá!"}], stream=True)
for chunk in res:
    if chunk.choices[0].delta.content:
        print(f"TTFT: {time.time()-t0:.4f}s"); break

Output Estruturado com Pydantic e Instructor

import instructor, openai
from pydantic import BaseModel

class UserLog(BaseModel):
    user_id: int
    action: str
    is_suspicious: bool

client = instructor.from_openai(openai.OpenAI())
log = client.chat.completions.create(
    model="gpt-4o-mini",
    response_model=UserLog,
    messages=[{"role": "user", "content": "Root login via SSH no port 22 às 03:00"}]
)
print(log.is_suspicious)

Melhores Práticas

  • Utilizar delimitadores claros (ex.: XML tags <context>) para prevenir injeções de contexto.
  • Validar schemas JSON estritamente usando Pydantic antes de processar em lógica de negócio.

Endpoint Assíncrono com Streaming SSE em FastAPI

from fastapi import FastAPI
from fastapi.responses import StreamingResponse
import asyncio

app = FastAPI()

async def generate_stream():
    for i in range(5):
        yield f"data: Token {i}\n\n"
        await asyncio.sleep(0.2)

@app.get("/stream")
async def stream():
    return StreamingResponse(generate_stream(), media_type="text/event-stream")

Melhores Práticas

  • Utilizar uv em vez de pip para resolução de dependências até 10x mais rápida.
  • Utilizar chamadas I/O não-bloqueantes (`async/await`) em todas as invocações de APIs externas.

Resiliência com Retry e Exponential Backoff (Tenacity)

from tenacity import retry, stop_after_attempt, wait_exponential

@retry(stop=stop_after_attempt(3), wait=wait_exponential(multiplier=1, min=2, max=10))
def call_api_with_retry():
    print("A tentar chamada à API...")
    # Chamada REST aqui
    raise Exception("Rate limit excedido 429")

Pesquisa Híbrida e Re-Ranking com FlashRank

from flashrank import Ranker, RerankRequest

ranker = Ranker(model_name="ms-marco-MiniLM-L-6-v2")
passages = [
    {"id": 1, "text": "Regra de Firewall bloqueia o porto 22 por defeito."},
    {"id": 2, "text": "Instalação do Docker em Ubuntu Linux."}
]
rerank_req = RerankRequest(query="como configurar firewall ssh", passages=passages)
results = ranker.rerank(rerank_req)
print(results)

Melhores Práticas

  • Combinar busca vetorial densa com busca por palavra-chave BM25 (Hybrid Search).
  • Aplica re-ranking após a primeira fase de retrieval para aumentar a precisão top-K.
